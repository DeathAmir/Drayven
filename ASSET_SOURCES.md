# Drayven asset sources and licenses

Drayven source code is open source. Third-party files retain their own licenses below. The build workflow vendors the exact upstream files into `assets/vendor/` and stores full license text in `licenses/`.

Source: https://opengameart.org/content/top-down-man-with-gun-animated . Vendored as `assets/vendor/characters/topdown_man.png`.
- **Treasure chest top-down style** — brandav. License: CC0 1.0 / public domain. Source: https://opengameart.org/content/treasure-chest-top-down-style . Vendored closed/open images as `chest.png` and `chest_open.png`.
- **Psycho Punch / Loop / FPS / Shoot 'em up** — KiluaBoy. License: CC0 1.0. Source: https://opengameart.org/content/psycho-punch-loop-fps-shoot-em-up . Attribution is optional per the author; credit to Kilua Boy is appreciated. Vendored as `assets/vendor/music/psycho_punch.ogg`.
- **Laser** — frosty ham. License: CC0 1.0. Source: https://opengameart.org/content/laser . Source page says no credit is needed, but credit is appreciated. Vendored as `assets/vendor/sfx/laser.wav`.
- **Click** — frosty ham. License: CC0 1.0. Source: https://opengameart.org/content/click-0 . Vendored as `assets/vendor/sfx/click.wav`.
- **Kenney game assets** — selected files from Space Shooter, Platformer Base and Onscreen Controls packs. License: Creative Commons CC0. Kenney support documentation states game assets on asset pages are CC0 and attribution is not required; optional credit: `Kenney`. Source mirror used for exact bytes: https://github.com/iwenzhou/kenney . Upstream: https://kenney.nl/ . Vendored files include the background, splash sample, application icon, enemy PNGs, flag, fireball, textured menu buttons, and textured touch controls.

The complete CC0 1.0 legal code is stored at `licenses/CC0-1.0.txt`.
